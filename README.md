# Sales Analytics Dashboard

## Project Overview
This project analyzes retail sales data using Python, SQL, and Power BI.

The dashboard provides insights into:

- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Profit Margin
- Monthly Sales Trends
- Sales by Region
- Profit by Category

## Tools Used

- Python
- Pandas
- Matplotlib
- SQL
- Power BI

## Dashboard KPIs

- Total Sales: $2.30M
- Total Profit: $286.40K
- Total Orders: 5,009
- Average Order Value: $458.61
- Profit Margin: 12.47%

## Key Insights

- West region generated the highest sales.
- Technology category produced the highest profit.
- Sales generally increased toward the end of the year.
- Overall profit margin was approximately 12.47%.
